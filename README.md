# claude-skills

Personal Claude Code user skills.

## Install

```bash
git clone git@github.com:StephanMunsch/claude-skills.git ~/_code/claude-skills
~/_code/claude-skills/install.sh
```

`install.sh` symlinks each directory under `skills/` into `~/.claude/skills/`, so edits in the repo are live immediately. Re-run it after adding a new skill.
